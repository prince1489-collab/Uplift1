# Android config

Mirrors `ios-config/`, which holds the committed `GoogleService-Info.plist` that
`scripts/inject-google-plist.cjs` copies into the generated iOS project.

## `google-services.json` — you need to add this

**It is not in the repo, and the build will warn loudly until it is.**

The TWA never needed it: a Trusted Web Activity is just the website running in Chrome, so
there was no native app for Firebase to configure. A Capacitor app is a real Android app,
and `@capacitor-firebase/messaging` needs the native Firebase config or push notifications
silently do nothing.

To generate it:

1. Firebase console → project **uplift-6d9ea**
2. Add app → Android
3. Package name: **`app.seenapp.twa`** — this must match exactly. It is the package Play
   already knows, and the reason we kept it rather than minting a new one.
4. Download `google-services.json` and commit it here as
   `android-config/google-services.json`

The Codemagic workflow copies it into `android/app/` after `cap add android`, because the
native folder is generated fresh on every build and is not committed.

## Why the package name lives in Gradle, not capacitor.config.json

Capacitor supports a single `appId`, and ours is `app.seenapp.ios` — the identifier the App
Store listing is bound to. Changing it to set the Android package would silently move the
iOS bundle identifier out from under that listing.

So the workflow patches `applicationId` in `android/app/build.gradle` after the platform is
added. Same repo, two package names, neither treading on the other.

## Signing

`app.seenapp.twa` already exists in Play with an upload key generated by PWABuilder when the
TWA was packaged. **An AAB built here must be signed with that same upload key** — a matching
package name is not sufficient; Play rejects a key mismatch outright.

- Still have the PWABuilder keystore → add it in Codemagic under
  *Teams → Code signing identities → Android keystores*, with reference name `seen_upload`,
  and the workflow below will use it.
- Don't have it → Play Console → *Setup → App integrity → Request upload key reset*. This
  takes a few days, so start it before you need the build.
